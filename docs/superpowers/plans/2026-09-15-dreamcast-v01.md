
# Dreamcast v0.1 Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Build a standalone Helengine Dreamcast ELF that initializes KallistiOS video and reliably renders a rotating, opaque, unlit six-color cube with host-tested transform, clipping, projection, and diagnostics.

**Architecture:** Keep cube data and CPU geometry in a KOS-independent module. Its fixed-capacity output is a narrow contract consumed by a native KOS PVR renderer, so packet layout, list ownership, video lifetime, and timing remain platform code. Use one Linux Docker toolchain route, direct pvr_prim() submission to the opaque polygon list, and Flycast direct ELF/HLE launch for first executable validation.

**Tech Stack:** C++17, KallistiOS at commit fcfa7d869471591ca1c777543261a7bfea7cb726, the KOS sh-elf/kos-c++ wrappers with pinned -m4-single ABI, GNU Make, PowerVR2 native PVR APIs, PowerShell entry points, Docker, and Flycast direct ELF/HLE.

**Spec:** docs/superpowers/specs/2026-09-15-dreamcast-v01-design.md

## Global Constraints

- “Build a standalone Helengine Dreamcast executable that initializes video and reliably renders a rotating, unlit cube.”
- “Confirmed scope: Native host and cube first. Helengine editor, generated runtime, scene export, and platform-builder integration belong to a subsequent milestone.”
- Use KOS revision fcfa7d869471591ca1c777543261a7bfea7cb726 as the candidate pin, and verify its toolchain, examples, and executable build before accepting the environment.
- Use C++ with KallistiOS and a native PVR renderer; keep transform, projection, and clipping separate from PVR packet emission.
- Initial display target is 640 × 480, RGB565, 4:3, with KOS-managed buffering and detected-cable mode selection. Do not force VGA-only output on a TV connection.
- The cube has 24 face-local vertices and 12 indexed triangles, six opaque face colors, no lighting, textures, fog, blending, transparency, or normals.
- Camera space uses +X right, +Y up, and positive depth d in front of the camera. Clip against d >= near, project with q = 1 / d, submit q as PVR depth, and use the compatible greater-depth comparison.
- Use independent three-vertex strips terminated with PVR_CMD_VERTEX_EOL; the unclipped cube emits 36 vertex records. Strip optimization is deferred.
- Use fixed scratch storage. One clipped input triangle produces at most four polygon vertices and two output triangles.
- Enable depth testing, depth writes, and backface culling explicitly after winding validation. A diagnostic mode may disable culling.
- KOS owns rendering and page flips. Do not add manual framebuffer swapping or an independent per-frame VBlank wait.
- Keep generated output and logs under C:\dev\helworks\builds\helengine-dc\<build-id> and out of Git. Keep SDK installations separate from project sources.
- Do not add editor/export integration, generated runtime, assets, textures, lighting, audio, VMU saves, engine input APIs, physics, UI, visibility/LOD, custom assembly, SH4ZAM, Store Queue tuning, vertex DMA, render-to-texture, or disc-image production.

**Interfaces:**

- Consumes: no KOS APIs. DreamcastCubeMesh supplies face-local source positions, colors, and triangle indices. The implementation receives an affine cameraFromModel matrix and a GeometryConfig.
- Produces: this exact renderer-neutral API. GeometryFrame contains pixel-space x/y, positive reciprocal depth z=q, and interpolated float RGBA values; Task 2 converts those values to the verified KOS vertex packet.

~~~cpp
namespace helengine::dreamcast {

struct Vec3 { float x, y, z; };
struct ColorRgba { float r, g, b, a; };
struct SourceVertex { Vec3 position; ColorRgba color; };
struct TriangleIndex { std::uint16_t a, b, c; };

struct CubeMeshView {
    const SourceVertex* vertices;
    std::uint16_t vertexCount;
    const TriangleIndex* triangles;
    std::uint16_t triangleCount;
};

// Row-major storage. Transform with cameraPoint = cameraFromModel * [x,y,z,1].
struct Matrix4x4 { float m[4][4]; };

struct GeometryConfig {
    float viewportWidth;
    float viewportHeight;
    float verticalFovRadians;
    float nearPlane;
};

struct ProjectedVertex {
    float x;
    float y;
    float z; // q = 1 / positive camera-space depth
    ColorRgba color;
};

struct ProjectedTriangle { ProjectedVertex vertices[3]; };

struct GeometryFrame {
    static constexpr std::uint16_t kMaxTriangles = 24;
    ProjectedTriangle triangles[kMaxTriangles];
    std::uint16_t triangleCount;
    std::uint16_t rejectedTriangleCount;
    std::uint16_t clippedTriangleCount;
    std::uint16_t emittedVertexCount;
    bool overflow;
};

enum class GeometryStatus : std::uint8_t {
    Ok,
    InvalidConfig,
    NonFiniteInput,
    OutputCapacityExceeded,
};

GeometryStatus processGeometry(const CubeMeshView& mesh,
                               const Matrix4x4& cameraFromModel,
                               const GeometryConfig& config,
                               GeometryFrame& output) noexcept;

CubeMeshView cubeMesh() noexcept;

} // namespace helengine::dreamcast
~~~

- processGeometry() clears all counts before processing, emits no partial frame when output capacity is exceeded, and returns Ok for a valid frame containing zero visible triangles. It never allocates, calls KOS, or writes outside GeometryFrame::kMaxTriangles.

- [ ] Step 5: Implement signed near-plane clipping and projection. ~~~text
q = 1 / d
fy = viewportHeight / (2 * tan(verticalFovRadians / 2))
fx = fy
screenX = viewportWidth / 2 + fx * x * q
screenY = viewportHeight / 2 - fy * y * q
~~~

namespace helengine::dreamcast {

struct VideoConfig {
    std::uint16_t requestedWidth = 640;
    std::uint16_t requestedHeight = 480;
};

struct VideoState {

    std::uint16_t height;
    std::uint32_t refreshHz;
    bool initialized;
};

class DreamcastVideo {
public:
    bool initialize(const VideoConfig& config, VideoState& state) noexcept;
    void shutdown() noexcept;
};

enum class HostScene : std::uint8_t { ClearOnly, ScreenTriangle, Cube };

struct HostConfig {
    HostScene scene = HostScene::Cube;
    bool animate = true;
    bool disableCulling = false;
    bool reverseTriangleOrder = false;
    bool nearPlaneProbe = false;
    bool screenEdgeProbe = false;
    float stopAfterSeconds = 0.0f; // zero means run until Start or shutdown
};

struct RendererConfig {
    bool disableCulling = false;
    bool reverseTriangleOrder = false;
};

struct RendererDiagnostics {
    std::uint32_t submittedTriangles;
    std::uint32_t submittedVertices;
    std::uint32_t clippedTriangles;
    std::uint64_t waitReadyNanoseconds;
    std::uint64_t lastFrameNanoseconds;
    std::uint32_t availableVramBytes;
    std::uint32_t parameterBufferHighWaterBytes;
};

class DreamcastRasterRenderer {
public:
    bool initialize(const VideoState& video, const RendererConfig& config) noexcept;
    bool renderFrame(const GeometryFrame& geometry) noexcept;
    RendererDiagnostics diagnostics() const noexcept;
    void shutdown() noexcept;
};

int runDreamcastHost(const HostConfig& config) noexcept;

} // namespace helengine::dreamcast
~~~
